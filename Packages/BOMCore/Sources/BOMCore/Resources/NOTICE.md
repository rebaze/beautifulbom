# Third-party files

`spdx.schema.json` is the CycloneDX SPDX licence enumeration (`$comment` "v1.1-3.28.0") from the
CycloneDX specification (https://github.com/CycloneDX/specification, `schema/spdx.schema.json`),
licensed under the Apache License 2.0. It is the same file rio 0.10.2 embeds, so both tools know
the same licence and exception identifiers.
