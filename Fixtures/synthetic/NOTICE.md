# Synthetic SBOMs

Written by hand for the tests: CycloneDX 1.6 documents with nested components and the edge cases
of the TR-03183-2 rules, and an SPDX 2.3 document (`shop-2.3.spdx.json`) with every relationship
the SPDX reading handles. "Acme Devices" and its components are invented; real package names
(openssl, curl, zlib) appear only as names, with no data from any product.
